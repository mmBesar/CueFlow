# Changelog

## [0.1.0] — First public release

- Initial native Qt Quick teleprompter for Linux and Android.
- Markdown display with Arabic/English bidirectional text handling.
- Direct LAN remote control with a pairing PIN.
- Smooth scrolling, seek/nudge controls, typography controls, fullscreen, and desktop keyboard shortcuts.
- Catppuccin flavors and accent selection.
- Linux x86_64/aarch64 Qt bundles and AppImages, dedicated NixOS package output, modern Android arm64 APK, and legacy Android ARMv7 APK.
- Custom CueFlow app icon integrated into the app header, native window, Linux launcher/AppImage, and Android launcher resources.
