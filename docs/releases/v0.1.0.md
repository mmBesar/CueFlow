# CueFlow 0.1.0

**The first public CueFlow release.** This is an early release of a native Markdown teleprompter built with Qt Quick. Linux and Android are the supported targets for this release.

## Highlights

- **Display and remote in one app.** Run CueFlow full-screen to read a script, or connect directly over your local network from a second CueFlow device to control playback and send a script.
- **Markdown and mixed-direction text.** Render Markdown, with automatic per-block bidirectional handling for Arabic/English text.
- **Comfortable playback controls.** Smooth pixel-per-second scrolling, play/pause, reset, position seeking, font size and text-width adjustment, and fullscreen controls.
- **Keyboard control on desktop.** Space toggles play/pause; Up/Down nudge the reading position; Left/Right decrease/increase the speed.
- **Catppuccin appearance.** Four flavors and 26 selectable accent colors.
- **Architecture-specific Linux packages.** AppImages and installable Qt bundles for x86_64 and aarch64, plus a separate NixOS store-closure archive.
- **Modern and legacy Android targets.** A 64-bit ARM APK for Android 9+ and a separate 32-bit ARM legacy APK for older devices that support `armeabi-v7a`.

## Downloads

Choose the package matching the operating system and CPU architecture. Linux AppImages are the easiest option to try; the Qt bundle is a fallback with a per-user installer. NixOS users should use the NixOS asset or the Nix flake rather than the generic Linux package.

Android APKs are signed with the project's configured release key. Ordinary CI APKs are debug-signed test builds and cannot be upgraded in-place to these signed release APKs. Before switching from a debug build, save any script text you need and expect to uninstall the test APK first; Android removes that app's private settings when it is uninstalled.

## Important limitations

- CueFlow is early software. Test the exact controls and script formatting on your device before relying on it for a live presentation.
- Remote control currently uses a direct, unencrypted TCP connection protected by a pairing PIN. Use it only on a trusted LAN; do not expose it to the public Internet.
- AppImages bundle Qt/QML and most application-side libraries, but still rely on compatible host glibc, graphics drivers, window-system libraries, and AppImage execution support. If one does not launch on a distribution, try the matching tarball or its native package route.
- Android compatibility depends on the device ABI. The legacy APK is only for 32-bit ARM devices and is not the recommended build for new phones.
- Windows and macOS packages are not provided in this release.

## Integrity

Verify downloads with `SHA256SUMS` before installing them.
